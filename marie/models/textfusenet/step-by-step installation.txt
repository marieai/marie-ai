Step-by-step installation:

This checkout no longer keeps a separate TextFuseNet environment. Use the
repository Python 3.12 / uv environment and the repo-local detectron2 wheel.

From the repository root:

uv sync --extra cu130 --group dev

To rebuild detectron2 for the PyTorch 2.12 / CUDA 13 lane:

MARIE_TORCH_ENV_NAME=marie-ai-pytorch-2-12 \
  scripts/setup-py312-torch212-cu130.sh build-detectron2
